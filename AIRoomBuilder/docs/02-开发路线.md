## 下一步任务的 AI 提示词

给其他 AI 下任务时，务必带上**约束和验收标准**，否则它会自由发挥出一堆你不想要的东西。

### S5 · 接入真实视觉模型

```
项目已有视觉模型适配层，位于 backend/app/services/vision.py，
目前有 mock / openai / dashscope / gemini 四个 provider，通过 .env 的 VISION_PROVIDER 切换。

请帮我做 Prompt 调优实验：
1. 在 backend/ 下写一个脚本 eval_prompt.py，批量跑 tests/images/ 下的照片
2. 对每张图输出：识别品类列表、靠墙关系、耗时、token 消耗
3. 支持对比多个 prompt 版本，输出对比表格

约束：
- 不要修改 scene.json 协议
- Prompt 必须继续只输出俯视平面坐标和 size_class，绝不输出米制尺寸
- 结果缓存机制要保留，key 里必须包含 prompt 版本号
```

### S6 · 家具模型库

```
项目的 3D 场景渲染在 frontend/src/three/RoomRenderer.ts，
家具通过 scene.json 里 asset.url 指向的 glb 加载，缺失时降级为 primitives.ts 的参数化几何体。

请帮我做一个模型库管理方案：
1. 在 models/ 下建立目录结构和 manifest.json，记录每个 glb 的品类、来源、许可证、原始尺寸
2. 写一个 scripts/check_models.py，校验 manifest 与实际文件是否一致，
   并列出 catalog.py 中还缺 glb 的品类
3. 补充一个模型预览页，网格展示所有已有模型

约束：
- 只接受 CC0 / 可商用许可
- glb 单个文件不超过 2MB，超过的要说明如何用 gltf-transform 压缩
- 不要修改 RoomRenderer 的归一化逻辑（它已能把任意尺寸的 glb 缩放到声明尺寸）
```

### S7 · 交互编辑

```
在 frontend/src/three/RoomRenderer.ts 基础上增加编辑能力：
1. 用 TransformControls 实现选中家具后拖拽移动（只允许在 XZ 平面移动）
2. 支持 Q/E 键按 15° 步进旋转
3. 拖拽时实时检测与其他家具的重叠，重叠时高亮为红色
4. Delete 键删除选中家具
5. 编辑结果写回 scene.json 并调用 PUT /api/scenes/{id} 保存

约束：
- 家具不得移出房间边界，用现有的房间尺寸做钳制
- 编辑后的物体，其 source 字段要改为 "user"
- 不要引入新的状态管理库，用现有的 Pinia store
```

### S8 · 自然语言改布局

```
后端已有 backend/app/services/prompts.py 中的 EDIT_SYSTEM_PROMPT，
定义了 move / rotate / remove / add 四种 JSON 补丁操作。

请实现：
1. POST /api/scenes/{id}/edit 接口，入参 { "instruction": "把沙发移到窗户旁边" }
2. 把当前 scene.json 精简后（只保留 id/category/label/position/against_wall）连同指令发给 LLM
3. 解析返回的补丁数组，应用到 scene.json
4. 应用后必须重新跑一遍 scene_builder 的布局求解（钳制 + 去重叠），
   因为 LLM 给的新位置同样可能穿模
5. 前端加一个指令输入框，支持撤销

约束：
- 补丁操作要做白名单校验，不接受未定义的 op
- 找不到对应 id 的补丁要跳过并记入 warnings，不能整体失败
```

## 给 AI 下任务的三条原则

1. **一次一个可验收的目标。** "帮我开发一个 AI 房间重建系统" 会得到一堆跑不起来的代码。
2. **永远附上约束。** 尤其是"不要改什么"——AI 最爱顺手重构你刚调好的东西。
3. **先给它现有代码的位置。** 说清楚 `backend/app/services/vision.py` 已经有什么，
   比让它猜要省掉一轮返工。

---

## 什么时候才该上原方案里的重型组件

| 组件 | 触发条件 |
| --- | --- |
| PostgreSQL | 需要多人协作，或数据量 > 10 万行 |
| Celery + Redis | 单次分析 > 30 秒，或需要任务重试 / 优先级队列 |
| Docker | 要部署到服务器时 |
| Depth Anything | 房间尺寸手调成为明显痛点时 |
| SAM2 | 需要从照片提取真实材质贴图时 |

在此之前，它们只会拖慢你。
