运行方式（重要）
本页面用原生 XMLHttpRequest 调用后端，不依赖 jQuery、不封装任何请求库，每个接口都是一段独立的过程式代码。
后端 CORS 仅放行 http://localhost:5173，推荐运行方式：把本目录两个文件复制到 frontend/public/，启动前端（npm run dev）后访问 http://localhost:5173/api-demo.html，并把下方「API 基础地址」设为 /api（默认值）。
若直接双击打开（file://），会因跨域被拦截；此时可临时把后端 main.py 的 CORS allow_origins 改为 ["*"]，并把下方地址设为 http://127.0.0.1:8000/api。
